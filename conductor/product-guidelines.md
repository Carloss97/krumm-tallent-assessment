# Product Guidelines

## UX Principles
- **Engaging and Gamified**: The platform should use gamification elements (e.g., progress bars, interactive feedback) to keep users engaged during data collection.
- **Professional and Efficient**: While being engaging, the platform must remain a professional tool for researchers, ensuring efficient data collection and clear navigation.
- **Accessible and Intuitive**: All interactive elements should be easy to understand and use, regardless of the user's technical proficiency.

## Prose and Style
- **Academic and Precise**: Instructions and reports should use academic and precise language, ensuring scientific clarity and accuracy.
- **Direct and Objective**: Avoid conversational filler and focus on providing clear, actionable information.

## Visual Design
- **Vibrant and Playful**: The UI should feature a vibrant and playful aesthetic to encourage user participation, using bright colors and dynamic animations (e.g., via Framer Motion).
- **Modern Dashboard Style**: Data visualization and reporting should use a modern, clean dashboard layout (e.g., via Recharts).

## Error Handling and Feedback
- **User-Friendly Notifications**: Errors should be presented as clear, helpful notifications that suggest a resolution without disrupting the user's flow.
- **Real-time Feedback**: Provide immediate visual feedback for user actions within the games to maintain engagement.
