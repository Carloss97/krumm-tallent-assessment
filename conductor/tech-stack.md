# Technology Stack

## Core Technologies
- **JavaScript**: Primary programming language.
- **React (v19)**: Frontend framework for building the user interface.
- **Vite (v8)**: Build tool and development server.

## Libraries and Utilities
- **Framer Motion**: Used for interactive animations and transitions.
- **Recharts**: Used for rendering telemetry data and performance charts.
- **React Router (v7)**: Used for managing navigation and routing.
- **Lucide React**: Icon library for consistent visual elements.
- **Classnames**: Utility for conditionally applying CSS classes.

## Development and Quality
- **ESLint**: Linting and code quality tool.
- **Vitest**: Testing framework for unit and integration tests.
- **React Testing Library**: Library for testing React components.
- **CSS (Vanilla)**: Styling strategy for the platform.
